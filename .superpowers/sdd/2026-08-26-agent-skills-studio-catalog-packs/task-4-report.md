## Self-review

- Dependency graph is acyclic: the generator imports `loadValidatedCatalog`; validation and generation both consume pure assembly/byte-check helpers from `scripts/lib/catalog.mjs`; validation never imports the generator.
- Source validation remains the complete Tasks 2–3 validation path. Generation receives loaded data only after it passes and throws one `AggregateError` containing every deterministic source error otherwise.
- Generated JSON is excluded only when deriving/checking expected output; default catalog validation retains its existing recursive malformed-JSON check, preventing any weakening of Tasks 1–3 validation.
- Recursive object-key canonicalization occurs before hashing; skill records are slug-sorted and pack digest/output order is derived from deterministic source discovery plus active/planned grouping.
- Filter arrays and keyed count maps are deterministically sorted; active pack member order is retained from the canonical pack slug list.
- Output contains source `updatedAt` metadata but no generation timestamp, absolute path, or filesystem enumeration order.
- The generated artifact is byte-for-byte regenerated with two spaces and one final newline.
- No dependencies, package metadata, package scripts, lockfiles, or unrelated files changed.

## Follow-up fix: exact generated-artifact byte checks

### Scope

Changed only generated-artifact freshness comparison. `checkCatalogBytes` now reads the artifact as a `Buffer` and compares it with `Buffer.from(serializeCatalog(expected), "utf8")` through `Buffer.equals`; it no longer decodes the artifact as UTF-8 before comparison.

### RED/GREEN regression evidence

The focused test serializes a valid expected catalog containing U+FFFD, then replaces that character's three UTF-8 bytes in the artifact with the invalid byte `0xFF`. Node's UTF-8 decoder converts `0xFF` to U+FFFD, so the prior decoded-string comparison incorrectly returned current.

RED:

```text
node --test --test-name-pattern='invalid UTF-8 bytes' scripts/generate-catalog.test.mjs
```

Result: exit `1`; the check returned `[]` instead of the stale-artifact error.

GREEN:

```text
node --test --test-name-pattern='invalid UTF-8 bytes' scripts/generate-catalog.test.mjs
```

Result: 1 passed, 0 failed; the invalid byte now reports `catalog/generated/catalog.json is stale; run npm run catalog:generate`.
