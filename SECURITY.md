# Security / Segurança

If you find a vulnerability in the site, installers, plugin, or skills, please
use [GitHub's private vulnerability reporting](https://github.com/jhonatan-oliveiradev/agent-skills/security/advisories/new).
Include the affected component, a way to reproduce the issue, and its potential
impact. Do not include credentials or private user data in the report. Please
avoid publishing the details in a public issue or pull request while the report
is being assessed.

The current production branch is `main`; `dev` is used for preproduction
integration. Fixes for older tags are considered case by case. No fixed
response or disclosure timeline is promised.

Se encontrar uma vulnerabilidade no site, nos instaladores, no plugin ou nas
skills, use o [relato privado de vulnerabilidade no GitHub](https://github.com/jhonatan-oliveiradev/agent-skills/security/advisories/new).
Informe o componente afetado, como reproduzir o problema e o possível impacto.
Não inclua credenciais nem dados privados de usuários no relato. Evite publicar
os detalhes em uma issue ou PR enquanto o relato estiver em análise.

A branch de produção atual é `main`; `dev` é usada para integrar mudanças antes
da produção. Correções para tags antigas são avaliadas caso a caso. Não há prazo
fixo prometido para resposta ou divulgação.
